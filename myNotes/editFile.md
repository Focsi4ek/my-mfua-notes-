Основы редактирования текста

*Курсор*
Это простой текстовый файл.

Перемещение курсора:
- Home — начало строки
- End — конец строки
- PgUp — на один экран вверх (в начало документа при многократном нажатии)
- PgDown — на один экран вниз (в конец документа при многократном нажатии)
- Ctrl + Home — в самое начало документа
- Ctrl + End — в самый конец документа
- Ctrl + → — перемещение по слову вправо
- Ctrl + ← — перемещение по слову влево

Горячие клавиши (Управление):
- Ctrl + S — сохранение всего документа
- Ctrl + Z — отмена последнего действия
- Ctrl + Y — возврат последнего действия (повтор отмененного)
- Ctrl + A — выделить всё

Выделение текста:
- Ctrl + Shift + → — выделение по словам вправо
- Ctrl + Shift + ← — выделение по словам влево
- Shift + → — выделение посимвольно вправо
- Shift + ← — выделение посимвольно влево
- Shift + ↑ — выделение на строку вверх
- Shift + ↓ — выделение на строку вниз

Использование клавиши Tab:
- Tab — отступ в 2 или 4 пробела (красная строка), перемещение к следующему элементу формы или ячейке таблицы
- Shift + Tab — обратный сдвиг текста (удаление отступа) или перемещение к предыдущему элементу/ячейке
- Ctrl + Tab — переключение между вкладками или окнами в пределах одной программы
